# Трынька — инструкция проекта

Цель: полноценная многопользовательская карточная игра в Telegram Mini App.

Правила: https://sekastars.tilda.ws/trynkarules  
GitHub: https://github.com/esv1312-crypto/Tr  
Первоначальный хостинг: Render.

## Требования
- Все оригинальные механики: колода 24 карты, по 3 карты, очки, торговля, пас, поддержка, повышение, вскрытие, тёмная игра, свара и пересдача.
- От 2 до 8 игроков; стартовый баланс 1000; ставки 10–100 с учётом оригинальных правил.
- Яркий мобильный интерфейс, комнаты, приглашения, синхронизация и восстановление соединения.
- Сервер контролирует карты, ставки, баланс и победителя; чужие карты не раскрываются.
- Проверять Telegram initData на сервере, хранить секреты только в переменных окружения.
- Покрывать правила автоматическими тестами.

## Работа
Перед изменениями проверять GitHub и PROJECT_LOG.md. Вносить реальные изменения, запускать тесты, фиксировать коммиты, результаты и деплой. Не заявлять об успехе без подтверждения, не заменять игру макетом и не добавлять платные сервисы без необходимости.

## Готовность
Несколько реальных пользователей запускают Telegram Mini App и проходят полную партию по оригинальным правилам; тесты проходят, сервер развёрнут и проверен.
